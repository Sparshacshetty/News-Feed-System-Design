# News Feed System Design

## Overview
This project presents the High-Level Design (HLD) and Technical Design of a scalable News Feed System similar to Facebook, Instagram, and Twitter.

## Features
- User Authentication
- Follow/Unfollow Users
- Create Posts
- Like and Comment
- Personalized Feed Generation
- Caching
- Load Balancing
- CDN Integration

## Architecture
Microservices-based architecture.

## Technologies
- API Gateway
- Redis
- Kafka
- PostgreSQL
- Cassandra
- CDN

See folders for HLD and Technical Design documents.
